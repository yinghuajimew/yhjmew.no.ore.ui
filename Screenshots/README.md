# Screenshots

README 里引用的是按语言分开的两套图：

```
Screenshots/
├── en/            # README.md 用的（英文界面）
│   ├── home.png
│   ├── downloads.png
│   └── settings.png
└── zh/            # README.zh-CN.md 用的（中文界面）
    ├── home.png
    ├── downloads.png
    └── settings.png
```

| 文件名 | 拍什么 |
|---|---|
| `home.png` | 主界面：下载游戏 / 普通处理（共存处理）+ 日志区 |
| `downloads.png` | 下载列表：进度、暂停、处理按钮 |
| `settings.png` | 设置面板：签名 / so / 下载线程数 / 语言 |

建议宽度 720px 左右、PNG，手机竖屏原图即可。
截图里的版本号、路径无所谓，但别露出自己的签名文件路径或密钥别名。
